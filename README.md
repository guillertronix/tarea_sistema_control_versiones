# Introducción a Git y Git Flow

## ¿Qué es Git?

Git es un sistema de control de versiones que permite guardar los cambios realizados en un proyecto. De esta manera, podemos consultar versiones anteriores, recuperar archivos y trabajar varias personas en el mismo proyecto.

## ¿Qué es Git Flow?

Git Flow es una metodología de trabajo que utiliza diferentes ramas de Git para organizar el desarrollo de un proyecto. Cada rama tiene una función, por ejemplo, desarrollar nuevas funcionalidades, preparar versiones o corregir errores.

Las ramas principales son `master` y `develop`. También se utilizan ramas como `feature`, `release` y `hotfix`.

## ¿Por qué utilizamos Git Flow?

Utilizamos Git Flow para organizar mejor el trabajo, separar las nuevas funcionalidades del código principal y evitar problemas al integrar los cambios.
