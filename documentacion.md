# Proceso

## 1. Usuario 1: Repositorio y estructura inicial

Primero, creé el repositorio utilizando la metodología Git Flow y lo subí a GitHub. Después, inicié una feature para implementar la estructura inicial de la página web, incluyendo la cabecera, la barra de navegación, el contenido principal y el pie de página.

## 2. Usuario 2: Contenido y atributos HTML

El usuario 2 creó dos features. La primera fue `feature/contenidoHTML`, donde se añadió un ejemplo para modificar el contenido de un párrafo utilizando JavaScript. La segunda fue `feature/atributosHTML`, donde se añadió un ejemplo para cambiar el atributo `src` de una imagen.

## 3. Usuario 3: Estilos CSS y release

El usuario 3 creó la feature `feature/estilosCSS`, donde se añadió un ejemplo para modificar el tamaño del texto utilizando JavaScript. Al crear la feature, me equivoqué y utilicé el nombre `estilosHTML` en lugar de `estilosCSS`.

Después, creé una release con todas las features y la etiqueté como `v1.0`, preparando la primera versión del proyecto.

## 4. Usuario 1: Hotfix

Por último, el usuario 1 creó el hotfix `hotfix/mejorasV_1_0` para realizar mejoras en la sección de contenido HTML. Una vez terminadas las modificaciones, subí los cambios a GitHub.
